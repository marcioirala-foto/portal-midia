# portal-midia

Artes públicas do **AI Studio Portal**, guardadas aqui só para que o Metricool consiga buscá-las por um endereço público na hora de agendar.

Regras:
- Entra apenas arte que vai ser publicada no Instagram do Portal.
- Nunca entra material de cliente, foto com pessoas identificáveis ou qualquer coisa interna.
- O Metricool copia a imagem para o servidor dele na hora em que o post é criado; por isso a arte é apagada daqui logo em seguida e o repositório fica quase sempre vazio.
